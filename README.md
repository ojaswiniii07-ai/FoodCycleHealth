# FoodCycle Health 🌱
> **Tagline:** *Eat Better. Waste Less. Live Healthier.*

An intelligent, sustainability-focused food and wellness platform that blends leftover management, organic food-waste utilization, wellness guidance, and delivery food link analysis into a unified interface.

Built with **React + Vite**, featuring a modern UI inspired by food delivery apps (Zomato/Swiggy) and clean health-app aesthetics.

---

## 🌟 Key Modules

1. **🍽️ Leftover-to-Recipe Generator**
   - Enter leftover food names (e.g., leftover idlis, cooked rice, stale bread) or upload a photo.
   - Generates creative dishes (e.g., Idli Upma, Masala Fried Idli, Idli Chaat, Idli Manchurian, Stuffed Idli).
   - Detailed recipe steps, macro breakdown, and food-safety storage guidance.

2. **🥗 Wellness & Skin-Focused Food Guidance**
   - Select common concerns (Acne, Oily skin, Dry skin, Dry hair, General wellness).
   - Manual description input or optional report/photo upload.
   - Evidence-informed nutritional guidance: "Foods to Consider" vs "Foods to Limit" along with hydration and lifestyle advice.
   - Clear non-diagnostic disclaimers encouraging professional medical advice.

3. **♻️ Food Waste Utilization**
   - Practical, safe, and realistic household uses for organic waste (peels, coffee grounds, eggshells, vegetable scraps, and sugarcane residue/bagasse).
   - Composting, gardening, natural cleaning, and mulching tips.

4. **🔗 Food Link Nutrition Insights**
   - Paste links from food delivery platforms (e.g., Zomato, Swiggy).
   - Highlights nutritional observations (calorie density, saturated fats, sodium, blood sugar considerations).
   - Suggests healthier customization alternatives and sides.

## 🛠️ Tech Stack

- **Frontend:** React 18, Vite
- **Routing:** React Router v6
- **Styling:** Custom CSS with responsive card design and gradients
- **Icons/Visuals:** Emoji and modern iconography

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone git@github.com:ojaswiniii07-ai/FoodCycleHealth.git

# Navigate to project directory
cd FoodCycleHealth

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Production Build

```bash
npm run build
npm run preview
```
